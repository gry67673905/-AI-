# 智慧政务“一网通办”AI 助手

面向政务服务 **事项咨询、材料清单生成、流程导航和办件辅助** 场景的一体化智能服务平台。系统支持事项知识库 RAG、办事 Agent、群众端问答、工作人员端处理和后台事项管理。

> 软件实习项目作业 · 设计周数 4 周

---

## 一、项目介绍

围绕“群众咨询 → 事项匹配 → 材料清单生成 → 后台维护”的完整闭环，系统分为五个建设任务：

| 任务 | 内容 |
|---|---|
| 任务 1 | 政务事项知识库：办事指南、政策文件、材料模板、常见问题、窗口信息的入库与检索 |
| 任务 2 | 事项问答模块：根据用户问题返回办理条件、材料清单、办理流程、注意事项 |
| 任务 3 | 办事 Agent：事项检索、政务办件 SQL Agent、条件判断、材料生成、流程导航、流式语音咨询、转人工 |
| 任务 4 | 群众端：事项搜索、智能问答、材料预填提示、办理流程查看、历史咨询 |
| 任务 5 | 后台管理端：部门、窗口、工作人员、政务事项、办件记录、群众咨询管理 |

## 二、功能特性

- **群众端**：事项搜索（关键词/分类）、智能问答（流式输出 + 语音输入 + 转人工）、材料预填提示、办理流程查看、历史咨询回放、满意度反馈
- **工作人员端**：咨询工作台（接管/回复转人工）、办件处理（SQL Agent 自然语言查询 + 状态流转）、知识辅助（RAG 检索）
- **后台管理端**：工作台概览 + 部门/窗口/人员/事项/办件/咨询六类对象管理（全部支持增删改查）

## 三、技术栈

| 层 | 技术 |
|---|---|
| 前端框架 | Vue 3（`<script setup>` 组合式 API）|
| 构建工具 | Vite 5 |
| UI 组件库 | Element Plus |
| 路由 / 状态 | Vue Router 4 / Pinia |
| 后端 | Java（Spring Boot 待接入）|
| 数据 | 本地模拟数据（可无缝替换为 RESTful API）|

## 五、运行方式

前端需 Node.js（建议 ≥ 16）。首次运行安装依赖：

```bash
cd frontend
npm install
npm run dev
```

浏览器访问 **http://localhost:5173**，选择角色进入对应端。

生产打包：

```bash
npm run build   # 生成 dist/ 静态文件
```

## 六、后端说明

后端目前为 Java 占位工程（`src/App.java`），前端通过 `frontend/src/api/index.js` 访问本地模拟数据。接入真实后端时：

1. 将 `api/index.js` 中各函数替换为 axios 请求（函数签名已对齐 REST 接口设计）；
2. 在 `vite.config.js` 中打开 `/api` 代理指向 Spring Boot 服务。
